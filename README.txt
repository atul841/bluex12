BLUEEX LOGISTICS WEBSITE
========================
Static responsive HTML/CSS/JS website inspired by the supplied BlueEx Logistics reference image.

Files:
- index.html       Home
- about.html       About
- services.html    Services
- network.html     Network
- tracking.html    Shipment tracking demo
- contact.html     Quote/contact form demo
- css/style.css    Complete responsive styling + animations
- js/script.js     Navigation, scroll reveal, counters, tracking demo, form demo

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in a browser, or use VS Code Live Server.
3. Replace the placeholder company phone/email/address and image URLs with your real details.
4. The tracking and quote forms are front-end demos. Connect them to PHP/MySQL/API when you want real submissions/tracking.

DESIGN:
Blue + orange logistics theme, responsive mobile navigation, scroll-reveal animations, animated counters, hover effects, process timeline, map-style network section, tracking UI and quote form.
